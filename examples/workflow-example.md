# 예시 · 가상의 프로젝트 문서 개정

## Fixed로 요청

> 예제 프로젝트의 설치 안내 초안을 검토하고, 누락된 전제 조건을 보완해 주세요. 다른 실행기가 문서의 절차와 승인 범위를 확인해 주세요.

Hermes는 분석 Codex → 작성 Claude → 검증 Codex 순서의 계획을 준비합니다. 계획에는 대상 문서, 허용 변경 범위, 단계별 예상 호출과 예산 한도를 표시합니다. 이 시점의 상태는 승인 대기입니다.

사용자가 해당 계획을 승인하면 Codex가 요구사항과 검증 기준을 정리하고, Claude가 격리된 작업 공간에서 변경안을 작성합니다. Codex는 작성 결과를 원요청과 대조해 누락된 단계나 범위 초과 여부를 기록합니다. 검증을 통과하면 Hermes가 변경 결과와 검증 의견을 함께 제공합니다.

## 같은 요청을 Swap으로 계획

사용자가 Swap을 명시하면, 기능이 활성화된 환경에서 분석 Claude → 작성 Codex → 검증 Claude 순서의 별도 계획이 만들어집니다. 이 계획의 승인과 예산 검증은 Fixed와 독립적으로 이루어집니다. 승인 후 Codex가 코드 변경을 제안하는 경우 Hermes는 패치의 범위와 기준본을 확인한 뒤 적용 결과를 기록합니다.

## 실행 중 사용량 제한에 도달한 경우

Hermes는 마지막으로 확인된 단계와 남은 작업을 기록하고 진행을 보류합니다. 재개 전에는 제한 해소, 남은 예산, 승인 유효성 및 이전 호출의 처리 여부를 확인합니다.
